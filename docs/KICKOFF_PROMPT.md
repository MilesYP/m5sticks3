# 啟動 Prompt（貼進 Claude Code 當第一個任務）

> 用法：在 Claude Code 開啟本資料夾後，把下面「=== PROMPT 開始 ===」到「=== PROMPT 結束 ===」之間的內容整段貼給它。
> 這個任務只做「骨架 ＋ 模式 1 離線表情」這一個垂直切片，不碰網路/HID/RF，先把架構跑穩。

=== PROMPT 開始 ===

你是這個 M5StickS3 專案的結對工程師。先讀專案根目錄的 `CLAUDE.md` 和 `M5StickS3+RF Pack S3.md`，照裡面的架構與鐵則做。回覆用繁體中文並解釋術語。

**本次任務：建立專案骨架，並完成「模式 1：桌面 AI 語音伴侶」的離線表情版本。**先不做 Wi-Fi、音訊後端、HID、RF——那些之後再疊。

請依下列順序，每一步做完先讓我確認再繼續：

1. **專案初始化**
   - 建立 PlatformIO 專案（`platform = espressif32`、Arduino framework、目標 M5StickS3 的 ESP32-S3），設定正確的 PSRAM／Flash 參數。
   - 依賴先加 `M5Unified` / `M5GFX`。
   - 建立 `CLAUDE.md` 第 4 節的 `src/` 模組檔（先放空殼與介面），`.gitignore`，一份精簡 `README.md`。
   - 板子定義、PSRAM 模式、腳位若不確定，**先停下來問我或查官方規格，不要臆測**。

2. **狀態機骨架**
   - 實作 `mode_manager`：四個模式的 enum 與 `enter()`/`exit()` 介面（內容先留空），以及用正面實體按鈕循環切換模式的邏輯。
   - 實作 `killswitch`：正面按鈕長/連按觸發急停旗標，最高優先，先接到「停止當前模式」即可。
   - 實作 `input_hal`：開機做 I2C 掃描，印出掃到的位址，辨識 CardKB(`0x5F`)／Scroll(`0x40`)／皆無，螢幕顯示目前偵測到哪個輸入裝置。
   - 驗收：開機後螢幕顯示目前模式名稱與偵測到的輸入裝置；按正面鍵能在四個模式名稱間循環切換。

3. **模式 1 離線表情**
   - 在 `ui_grok` 用 M5GFX 向量繪圖畫 Grok 風極簡幾何表情：黑底高對比，Idle 呼吸浮動＋隨機眨眼。
   - 螢幕下方 25% 預留跑馬燈文字區，先顯示一行假字（例如 "idle…"）。
   - 非阻塞實作（用 `millis()` 排程動畫，不要用長 `delay`）。
   - 驗收：切到模式 1 時，看到會呼吸、會隨機眨眼的幾何表情，且切走再切回正常。

每步結束請附：改了哪些檔、如何編譯燒錄、怎麼驗收。遇到腳位或板子設定不確定，先問我。

=== PROMPT 結束 ===
