怎麼用這份計畫

照編號一關一關往下走，每關做完勾「完成」，進度會自己記住。前期不用買齊，第 0～4 關只要 StickS3 本體就能開始；Scroll Unit、CardKB、RF Pack 到貨後再接上對應的關卡。

把 Claude Code 當你的隨身助教。你不用背語法——遇到看不懂的錯誤、要補完程式、要查某顆晶片的腳位，就把畫面和這份計畫貼給它，請它解釋、生成、逐行帶你讀。你負責理解「為什麼這樣設計」，打字交給它。

M0 圖解 · firmware/ 骨架

M0 燒進板子後：畫面與操作

M0 還沒有任何真功能——四個模式都是「空殼」，切換時只在序列埠印出 exit()／enter()。它要驗證的是骨架：狀態機切得對、急停夠快、Grove 配件認得出來。下面的模擬器照 ui_status.cpp 的座標與顏色畫，按鍵邏輯照 main.cpp／input_hal.cpp 實作，可以直接按按看。

01s 重印報告3s 急停

鍵盤：A 正面鍵、按住 B 側鍵。換 Grove 配件要重新開機才會重掃（M0 只在開機掃一次）。

序列埠監看（Serial Monitor，115200）

狀態機：誰會跳到誰

手機上可左右滑動看完整圖。

按鍵配置（CLAUDE.md 第 2 節決議）

  • B 短按（<1 秒）：下一個模式；在 Safe 中＝解除急停
  • B 按住 1～3 秒後放開：序列埠重印狀態報告
  • B 按住滿 3 秒：全域急停（不用等放開）
  • A：只有 HidAgent 中是急停；其他模式 M0 先只印 log
  • 電源鍵：韌體不用（單擊重置、雙擊關機）

開機流程（setup）

  1. M5.begin() 初始化螢幕、按鍵、電源
  2. input_hal：開 Grove 5V → 等 200ms → 掃 I2C，認出 CardKB（0x5F）或 Scroll（0x40）
  3. killswitch：建立最高優先 task＋掛上 A 鍵中斷
  4. mode_manager：進 Desktop
  5. 畫第一張狀態畫面＋印一次報告

主迴圈（loop）每一圈

  1. 急停已觸發？→ 回收目前模式資源、進 Safe
  2. 讀按鍵事件 → 切模式／重印／急停
  3. 每 500ms 重畫一次畫面（顯示 uptime）

全程不用長 delay()，按鍵隨時有反應。

急停為什麼分兩段

  1. 第一段（微秒級）：按下 A 觸發硬體中斷，直接把「輸出閘門」關掉，不等主迴圈。
  2. 第二段（毫秒級）：主迴圈看到旗標，正式關掉模式資源、切進 Safe、畫紅底。

紅底畫面上的 gate: N us 就是第一段花了幾微秒，實機才量得到。

中斷（ISR）：硬體偵測到按鍵電位變化時，CPU 立刻暫停手上的事去跑一小段程式，不必等主迴圈輪到。Task：FreeRTOS 裡可以獨立排程的工作，優先權越高越先跑。Sprite（畫布）：先在記憶體裡畫好整張畫面再一次推到螢幕，避免閃爍。

M0 實機驗收清單

這一輪不用裝 RF Pack（M0 不碰 CC1101）。燒錄連不上時：長按電源鍵約 2 秒到綠燈閃 → 放開 → Upload，燒完短按電源鍵啟動。

// 用 M5Unified 函式庫，它會自動辨識 StickS3
#include <M5Unified.h>
int count = 0;
void setup() {
  M5.begin();                 // 初始化螢幕、按鈕、電源
  M5.Display.setTextSize(3);
  M5.Display.print("Hello StickS3");
}
void loop() {
  M5.update();                // 每圈更新按鈕狀態
  if (M5.BtnA.wasPressed()) { // 正面按鈕被按下
    count++;
    M5.Display.clear();
    M5.Display.setCursor(0, 0);
    M5.Display.printf("count: %d", count);
    Serial.printf("count=%d\n", count); // 送到序列埠除錯
  }
}

// I2C 掃描器：找出 Grove 上接了哪些裝置
#include <Wire.h>
void setup() {
  Serial.begin(115200);
  Wire.begin();               // Grove 的 I2C 腳位讓 Claude Code 依 StickS3 補上
  for (uint8_t a = 1; a < 127; a++) {
    Wire.beginTransmission(a);
    if (Wire.endTransmission() == 0)
      Serial.printf("found 0x%02X\n", a); // 掃到就印位址
  }
}
void loop() {}
