# M1-A 啟動 Prompt — 模式 1 離線表情（RoboEyes 風）

> 用法：在 Mac 的 VS Code 終端機啟動 Claude Code CLI（plan mode），貼上本檔。
> CLI 會讀到 `CLAUDE.md`、`docs/PROGRESS.md`、`docs/StickS3 介面規格.html`。
> **每個切片**：先給要改的檔案與計畫 → 我同意 → 寫 → `pio run` 編譯 → 燒錄 → 實機驗收 → `git commit`＋`push` → 下一片。

## 目標
在 M0 骨架上，把 **Desktop 模式** 從狀態畫面換成會動的桌寵表情。**本里程碑完全離線**（不連 Wi-Fi、不接語音，那是 M1-B）。風格與互動以 `docs/StickS3 介面規格.html` 第 2 節為準。

## 前置條件
M0 已實機驗收通過（開機、B 切模式、急停、Grove 偵測）。若尚未，先做 M0 驗收再開始。

## 不做（留給後續里程碑）
- Wi-Fi／語音／對話列（M1-B）
- 資訊頁（A 短按）、選單改版（各自里程碑）
- 麥克風「聲音觸發」若 ES8311 初始化會卡，先跳過，留切片 3 再評估

## 新增/修改檔案
- 新增 `firmware/src/ui_expression.h` / `.cpp`：表情繪製與情緒狀態機（M5GFX 向量繪製，sprite 先畫再推）。
- 改 `firmware/src/main.cpp`：`setup()` 呼叫 `ui_expression::begin()`；`loop()` 當 `mode==Desktop && !Safe` 時每圈 `ui_expression::render()`，其餘維持 `ui_status`。
- 改 `firmware/src/mode_manager.cpp`：`desktopEnter()/Exit()` 呼叫 `ui_expression` 的 resume/pause（配合鐵則二資源開關）。
- 情緒輸入來源：`M5.Imu`（BMI270，搖晃／傾斜）；聲音觸發延後。

## 切片順序（一片一編譯一燒錄一驗收）
### 切片 1 — Idle 離線表情（最小垂直切片）
- 兩個圓角方塊眼睛，青色，置中。
- 呼吸：眼高隨 `sinf(millis())` 緩慢起伏。
- 眨眼：每 2.5～4 秒隨機眨一次（眼高瞬間壓到最小再彈回）。
- 非阻塞：用 `millis()`，不可 `delay()` 卡住；急停與 B 切模式仍要即時。
- 驗收：開機進 Desktop 就看到會呼吸、會眨眼的臉；按 B 仍能切到其他模式（顯示原狀態畫面）；拍正面大按鈕急停仍即時。

### 切片 2 — 情緒與眼型
- 依 `介面規格` 第 2 節做 開心（黃・下弧）、生氣（紅・八字眉）、驚嚇（紫・縮小發抖＋冒汗）、想睡（半閉）、睡著（橫線＋Z）。
- 情緒切換平滑過渡（眼高/顏色補間），不要硬跳。
- 驗收：用序列埠指令或暫時用 B 長按循環各情緒，確認六種表情與顏色正確、過渡順。

### 切片 3 — IMU 互動
- 搖晃 → 驚嚇；傾斜 → 眼睛看向傾斜方向；放著 6 秒 → 想睡、11 秒 → 睡著；睡著時搖晃/翻動 → 驚嚇醒來。
- `M5.Imu.getAccel()` 取加速度；搖晃＝加速度變化量超門檻；傾斜＝重力分量。門檻寫成 `config.h` 具名常數。
- 驗收：搖一搖變驚嚇、傾斜眼睛跟著看、放著會睡著、動一下醒來。

### 切片 4 — 直/橫雙版面
- `M5.Imu` 判斷機身方向，`M5.Display.setRotation()` 切直(0)/橫；臨界角加遲滯避免抖動。
- 兩個方向眼睛都置中（橫式眼睛間距/大小依規格）。
- 驗收：轉動機身，表情在直式與橫式間切換且都置中，不會在臨界角來回跳。

## 工程約束（摘自 CLAUDE.md）
- 非阻塞主迴圈；大緩衝放 PSRAM、`exit()` 釋放。
- I2C 位址、腳位、門檻寫成具名常數。
- 原生 USB CDC 序列埠在電腦開啟前的訊息會遺失 → 以螢幕顯示為主、除錯訊息可重印。
- 每片都能單獨編譯；先寫 2～3 個函式驗證再展開。
